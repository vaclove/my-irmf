# Public websites — irmf.cz / irmf.net

Everything in this folder is about the festival's **public WordPress sites**, not about the
my.irmf.cz internal system that the rest of this repository implements. It is parked here because
the sites have no repository of their own — all changes to them happen directly on the server.

| | |
|---|---|
| `IRMF-WEB-RUNBOOK.md` | Access, backups, safe-change workflow, caches, 2026 colour scheme, key content IDs, annual rollover checklist, per-change log. **Start here.** |
| `plans/` | Larger pieces of work, written before doing them. Currently the 2026 rebuild of the English site. |

The runbook's §1 has the SSH hosts and paths; §3 has the workflow to follow before touching either
site.
